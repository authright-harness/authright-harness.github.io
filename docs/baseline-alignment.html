Intentional thin-MVP deviations (remaining)

  1. Engineering src/ layout instead of design §71 package tree
  2. Knowledge Graph not user-facing
  3. to-openspec is handoff, not a sixth §6 user intent
  4. LLM execution remains agent-delegated (orchestrator boundary exists; no mandatory hosted model in CLI)
  5. Technology / Framework registry not shipped yet

Superseded by P1–P8 apply: absolute “no orchestrator”, scan without evidence/hypotheses, change never auto-scans, explore/doctor markdown-only, flat package-only, heuristics-only review.

Surface already locked: five /auth:… intents; no greenfield/brownfield commands; no public analyze / status CLI; change --analyze / --ready; hidden validate / transition.
