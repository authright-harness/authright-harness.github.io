CLI reference

Global option: --path <dir> selects the project root.

CommandPurpose
authright init [path] --tools cursor,codex|noneCreate .authright/ + agent delivery
authright updateRegenerate managed authright-* skills/commands
authright scanHeuristic IAM discovery → context.yaml
authright change [intent…]Create DRAFT Auth Change
authright analyze [id|intent…]Analyze (omit id to create) → ANALYZED; refuses post-ANALYZED states
authright validate <id> [--export-ready]Schema + prerequisites
authright transition <id> <state>Legal lifecycle move (e.g. DECIDED). DECISION_REQUIRED is manual only
authright to-openspec <id> [--slug] [--force]Export to openspec/changes/… + specs/iam-change
authright status [id] [--json]Lifecycle + milestones
authright review <id>Heuristic verify from EXPORTED (keyword/checklist MVP)

Exit codes: 0 ok, 1 validation/lifecycle, 2 unexpected.

Notes:

  • There is no authright decide — edit decisions.yaml directly.
  • to-openspec fails if the target OpenSpec folder already exists unless --force.
  • init --force overwrites context/constitution only after confirm (or AUTHRIGHT_FORCE=1 non-interactive).
  • review is deterministic file heuristics for MVP — not a full security audit.
