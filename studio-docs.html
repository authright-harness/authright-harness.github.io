AuthRight Studio

AuthRight Studio is the local browser host for IAM Decide. It runs in the browser without Cursor, Claude Code, or Codex.

What Studio runs

Studio’s current closed loop is auto-plan Decide plus an IAM source-of-truth document in a Case:

  1. Install and open the browser host.
  2. Save a model in Settings → Models.
  3. Start a Case (send from the empty-list welcome, or click New Case) and describe the IAM ask in chat.
  4. When the answer includes a text decide section, answer the current question by typing a number, option id, or label.
  5. The Case folder ends with .authright/changes/ (DECIDED) and a source-of-truth file under .authright/docs/.

When you ask for the complete IAM solution write-up, that write-up is the chat answer. Studio does not offer a download. The Case still keeps a new timestamped file under .authright/docs/.

A Studio-only install does not require @authright/cli. Decide runs in-process from the engine embedded in @authright/studio.

What Studio does not run

Studio does not scan a repository, diagnose open routes, hand off to another tool, review an implementation, or edit application source. You can lock a decision without those steps. The idea is in Principles.

Install and open a Case

Node.js 20.19.0 or newer. @authright/cli and @authright/studio share one version when both are installed.

When both packages are installed at the same version:

The browser opens http://127.0.0.1:4317 unless you pass --no-open.

  1. After a model is ready, either describe the ask in the center welcome (empty Case list—Studio creates a Case on first send) or click New Case then chat. The title starts as IAM Decide.
  2. Watch Activity for tool steps. Reply to the text decide section when it appears.
  3. Read the solution in the chat answer when you asked for the complete write-up. The Case still keeps .authright/changes/ and a new timestamped file under .authright/docs/. Studio does not offer a download.

The open Case uses a bookmarkable URL (/c/<caseId>). See Cases.

What AuthRight Harness is

AuthRight Harness locks identity decisions before anyone writes auth code. It is not an identity provider. It does not host users, run login, or replace Keycloak, Entra, Auth0, or PingAM. It also does not write your application source.
