# AuthRight Harness

> Identity & Access Security Decision Layer for AI coding agents.

AuthRight Harness is the decision layer between your codebase and implementation. AI coding agents (Cursor, Codex, Claude Code) use AuthRight Harness to understand identity signals, record security decisions, and verify contracts before OpenSpec implements changes.

## Quick start

```bash
npm install -g @authright/cli@latest
authright --version
cd your-project
authright init --tools cursor,codex,claude
authright scan
```

Public loop: `explore|doctor` → `change` → `change <id> --analyze` → `--ready` → `to-openspec` → `review`.

Product intent names use colon form (`/auth:scan`, `/auth:explore`, …). Handoff: `/auth:to-openspec`. Cursor registers hyphen slashes from the filename (`/auth-scan`); Claude Code registers colon slashes from `.claude/commands/auth/` (`/auth:scan`); Codex skills use `$authright-scan`. `authright init` prints the installed hosts’ forms.

AuthRight Harness does not write application source. It prepares accepted identity-security decisions for an external OpenSpec apply step.
