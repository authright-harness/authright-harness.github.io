AuthRight Studio reference

Cases

A Case is one IAM Decide ask. It has a folder on disk and one chat thread. Switching Cases switches the chat, the Activity column, and the files Studio is allowed to write.

Create and switch

  1. Save a model first. New Case stays disabled until then. See Models.
  2. Click New Case. The title starts as IAM Decide until rename or the first Decide ask generates a title.
  3. The left rail lists Cases. Click one to open it. The center header shows that Case’s title and folder.

Use a new Case for a new ask. Two asks in one chat share one lock and become hard to read later.

The list can be collapsed. The count on Cases is how many unpinned Cases Studio shows there.

Rename, pin, and delete

Each Case row has a ⋯ menu:

ActionEffect
RenameOpens a dialog to change the display title (folder path stays the same).
Pin / UnpinMoves the Case into or out of the Pinned section (shown only when at least one Case is pinned).
DeleteAsks for confirm, then removes the Case folder, chat thread and messages, Activity/follow-up data, and that Case’s LLM trace.

You can also rename from the center header title. Pinned Cases appear only under Pinned, not again under Cases.

What you see in a Case

AreaRole
Left railNew Case, Pinned (when used), the Case list, Settings
CenterThis Case’s chat
RightActivity for the current turn: tool steps and paths

An empty chat shows a welcome section. It is not a fake assistant message.

Where the files are

The list of Cases (id, title, pin, folder, chat thread) is ~/.authright/studio/cases.json. Studio creates the folder when you click New Case. Decide artifacts appear under .authright/ as the chat runs.

Chat history for that Case is kept locally and restored when you reopen it. The files under .authright/ are the decision, not the chat scrollback.

Disk layout and the local HTTP API are in the Studio reference.
