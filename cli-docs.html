First loop

This is the AI coding agent + AuthRight Harness path (Cursor, Codex, or Claude Code). Install @authright/cli first — see Installation.

Day-to-day work happens in the agent chat after a one-time terminal bootstrap (authright init). Host skills/commands use the model. Bare terminal authright scan / change --analyze / similar verbs are offline only (no LLM)—do not use them as the happy path. Terminal flag detail lives under How commands work and CLI.

1. Initialize the project

In the repository root:

Terminal
$cd your-project
$authright init

Omit --tools to pick Cursor, Codex, or Claude Code interactively (detected hosts are pre-selected on first run). Pass a single host when you already know:

Terminal
$authright init --tools cursor
# authright init --tools claude
# authright init --tools codex

Init writes host commands/skills and .authright/AGENTS.md. Then open that same project in your agent.

2. Pick one Decide command

/auth:change (auto-plan) is the recommended first Decide path. /auth:explore (HITL) is the peer alternative for the same ask — pick one. Neither command is a mode, fallback, or prelude of the other. Recommended options in HITL or auto-plan are labeled — they are not already selected. --ready does not silently Implicit-Preserve; confirm the plan in chat first.

Host forms differ. Product names keep the colon (/auth:change); type what your host registered.

What the agent is doing

Skills use the host LLM and may shell offline public verbs under the hood (scan, change, plan confirm, --ready, and so on). You stay in chat: confirm the plan, then run request-match, then pick one handoff — Plan mode (to-plan) or OpenSpec (to-openspec). Omit the change id on those follow-ups while it stays in chat context. Export waits until request-match is clear. AuthRight does not write application source.

Both Decide paths start from an IAM Brief and an accepted slice. If context is missing or stale, intake can scan first; you can still run scan yourself. /auth:doctor (host forms: /auth-doctor, $authright-doctor, /auth:doctor) is optional anytime for a source risk report at .authright/diagnosis/report.md — it is not a required step between scan and Decide.

Installation

Install the AuthRight CLI (@authright/cli) for the coding-agent path (Cursor, Codex, or Claude Code).

Existing projects

AuthRight Harness is built for brownfield IAM: mixed IdPs, legacy sessions, partial OIDC, framework security that grew over years. You do not document the entire identity estate before the first useful change.
